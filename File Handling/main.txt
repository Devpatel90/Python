📁 File Handling in Python — Complete Guide
1. What is File Handling?

File handling means using Python to create, read, write, update, and delete files.

Python can work with files such as:

.txt — text files
.csv — tabular data
.json — structured data
.log — log files
Binary files such as images, PDFs, etc.

Basic flow:

Open file
   ↓
Read / Write / Append
   ↓
Close file
2. Opening a File

Python uses the open() function.

Syntax
file = open("filename.txt", "mode")

Example:

file = open("data.txt", "r")

Here:

data.txt → filename
"r" → mode
file → file object
3. File Modes

These are the most important modes:

Mode	Meaning
r	Read
w	Write
a	Append
x	Create new file
b	Binary
t	Text
+	Read and write
Common combinations
"r"    # read
"w"    # write
"a"    # append
"x"    # create
"r+"   # read + write
"w+"   # write + read
"a+"   # append + read
"rb"   # read binary
"wb"   # write binary
4. Reading a File

Suppose data.txt contains:

Hello Python
I am learning file handling
Python is easy
Method 1 — read()
file = open("data.txt", "r")

data = file.read()

print(data)

file.close()

Output:

Hello Python
I am learning file handling
Python is easy

read() reads the entire file.

5. Reading Specific Number of Characters
file = open("data.txt", "r")

data = file.read(5)

print(data)

file.close()

If the file starts with:

Hello Python

Output:

Hello

read(5) reads the first 5 characters.

6. readline()

readline() reads one line at a time.

file = open("data.txt", "r")

line = file.readline()

print(line)

file.close()

If:

Hello Python
I am learning Python
Python is powerful

Output:

Hello Python

You can call it again:

file = open("data.txt", "r")

print(file.readline())
print(file.readline())
print(file.readline())

file.close()
7. readlines()

readlines() reads all lines and returns them as a list.

file = open("data.txt", "r")

lines = file.readlines()

print(lines)

file.close()

Output:

['Hello Python\n', 'I am learning Python\n', 'Python is powerful\n']

Notice \n.

It represents a new line.

8. Reading Using a Loop

This is very common.

file = open("data.txt", "r")

for line in file:
    print(line)

file.close()

Better version:

file = open("data.txt", "r")

for line in file:
    print(line.strip())

file.close()

strip() removes unnecessary whitespace and \n.

9. Writing to a File

Use "w" mode.

file = open("data.txt", "w")

file.write("Hello Python")

file.close()

Now data.txt contains:

Hello Python
⚠️ Important

"w" overwrites existing content.

For example, if your file contains:

Hello
Python

and you run:

file = open("data.txt", "w")
file.write("New Data")
file.close()

The old content is deleted.

Now:

New Data

11. writelines()

You can write multiple strings using a list.

file = open("data.txt", "w")

lines = [
    "Python\n",
    "Java\n",
    "C++\n"
]

file.writelines(lines)

12. Append Data

Use "a".

Append means add new data at the end.

file = open("data.txt", "a")

file.write("\nJavaScript")

file.close()

If the file was:

Python
Java
C++

It becomes:

Python
Java
C++
JavaScript

Unlike "w", "a" doesn't delete existing data.

13. Difference Between w and a
w
file = open("data.txt", "w")
file.write("Hello")
file.close()

➡️ Deletes old content.

a
file = open("data.txt", "a")
file.write("Hello")
file.close()

➡️ Keeps old content and adds "Hello" at the end.

14. Creating a New File with x

x creates a new file.

file = open("newfile.txt", "x")

file.write("Hello")

file.close()

If the file already exists, Python gives:

FileExistsError
15. Closing a File

After working with a file:

file.close()

Example:

file = open("data.txt", "r")

print(file.read())

file.close()

Why close it?

Because files use system resources. Closing ensures those resources are released.

16. The with Statement ⭐

This is the recommended way to work with files.

Instead of:

file = open("data.txt", "r")

data = file.read()

file.close()

Use:

with open("data.txt", "r") as file:
    data = file.read()

print(data)

Python automatically closes the file.

You don't need:

file.close()
17. Why with is Better?

Suppose an error occurs:

file = open("data.txt", "r")

data = file.read()

x = 10 / 0

file.close()

Because the error happens before close(), the file might not be properly closed.

With:

with open("data.txt", "r") as file:
    data = file.read()
    x = 10 / 0

Python handles the cleanup automatically.

26. seek() — Move File Cursor

When reading a file, Python maintains a cursor.

Example:

with open("data.txt", "r") as file:
    print(file.read(5))
    print(file.read(5))

The first read(5) reads characters 1–5.

The second starts from character 6.

You can move the cursor using seek():

with open("data.txt", "r") as file:

    print(file.read(5))

    file.seek(0)

    print(file.read(5))

Output:

Hello
Hello

seek(0) moves the cursor back to the beginning.

27. tell()

tell() tells you the current cursor position.

with open("data.txt", "r") as file:

    print(file.tell())

    print(file.read(5))

    print(file.tell())

Example:

0
Hello
5
28. File Exception Handling ⭐

File handling can produce errors.

For example:

try:
    with open("data.txt", "r") as file:
        print(file.read())

except FileNotFoundError:
    print("File not found!")

This is much better than allowing your program to crash.

42. json.dump() vs json.dumps()
dump()

Writes JSON into a file:

json.dump(data, file)
dumps()

Converts Python data into a JSON string:

json_string = json.dumps(data)

print(json_string)

Similarly:

load()

Reads JSON from a file:

data = json.load(file)
loads()

Reads JSON from a string:

data = json.loads(json_string)

Remember:

dump  → Python → JSON file
dumps → Python → JSON string

load  → JSON file → Python
loads → JSON string → Python

56. Practical Program 11 — File Manager
import os

while True:

    print("\n1. Create File")
    print("2. Read File")
    print("3. Write File")
    print("4. Append File")
    print("5. Delete File")
    print("6. Exit")

    choice = input("Enter choice: ")

    if choice == "1":

        filename = input("Enter filename: ")

        try:
            with open(filename, "x") as file:
                print("File created.")

        except FileExistsError:
            print("File already exists.")

    elif choice == "2":

        filename = input("Enter filename: ")

        try:
            with open(filename, "r") as file:
                print(file.read())

        except FileNotFoundError:
            print("File not found.")

    elif choice == "3":

        filename = input("Enter filename: ")
        data = input("Enter data: ")

        with open(filename, "w") as file:
            file.write(data)

        print("Data written.")

    elif choice == "4":

        filename = input("Enter filename: ")
        data = input("Enter data: ")

        with open(filename, "a") as file:
            file.write("\n" + data)

        print("Data appended.")

    elif choice == "5":

        filename = input("Enter filename: ")

        if os.path.exists(filename):
            os.remove(filename)
            print("File deleted.")
        else:
            print("File not found.")

    elif choice == "6":

        print("Program exited.")
        break

    else:
        print("Invalid choice.")

57. File Handling + Functions

You can make file operations reusable.

def write_file(filename, data):

    with open(filename, "w") as file:
        file.write(data)

    print("File written successfully")


def read_file(filename):

    with open(filename, "r") as file:
        return file.read()


write_file("data.txt", "Hello Python")

data = read_file("data.txt")

print(data)

This is a good example of combining functions + file handling.

58. File Handling + OOP

You can also create a class:

class FileManager:

    def write(self, filename, data):

        with open(filename, "w") as file:
            file.write(data)

    def read(self, filename):

        with open(filename, "r") as file:
            return file.read()

    def append(self, filename, data):

        with open(filename, "a") as file:
            file.write(data)


manager = FileManager()

manager.write("data.txt", "Hello Python")

print(manager.read("data.txt"))

manager.append("data.txt", "\nHello AI")

This becomes useful in larger applications.
